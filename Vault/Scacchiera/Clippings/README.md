# Clippings (raw sources)

Drop raw captures here: Obsidian Web Clipper articles, transcribed papers,
pasted notes. Everything in this folder is IMMUTABLE. The wiki reads these and
never edits them. All interpretation and summarizing happens in
[Wiki/](../Wiki), never here.

After clipping an article with remote images, open it and press Ctrl+Shift+D to
pull the images into [assets/](../assets) so the vault stays self-contained.
