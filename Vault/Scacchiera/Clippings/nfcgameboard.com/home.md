## Strong features

Using standard ICode NFC tags, you are not dependent of a single supplier

Reader uses standard 15693 functions.

Low requirements on the microcontroller: 8-bit 20 MHz, 32KB ROM, 2KB RAM, 2KB EEPROM will do

## Recent Updates

##### [Redesign of the reader is ongoing!](https://nfcgameboard.com/2026/06/09/redesign-of-the-reader-is-ongoing/)

by benbulsink_nfc, [Uncategorised](https://nfcgameboard.com/category/uncategorised/)

Currently, a study is ongoing to use the NXP PN5180 multi-protocol reader for future designs! This study is executed with use of the widely available and affordable PN5180 modules. The Github available free libraries have been tested, and improved, and so the same speed is implemented as found with the CLRC632 reader: 9 ms Inventory, 12 ms ReadSingleBlock on one block. Will be continued!
