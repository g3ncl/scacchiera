# SSD1362

Solomon Systech 256 by 64, 16-gray-scale OLED controller fitted inside each of the two
[[er-oledm3-12-1w]] display modules. It is not purchased separately and has no independent board
designator or supplier order code in this product.

[mpn::SSD1362] [role::player display controller] [interface::four-wire SPI]

The exact interface, reset, electrical and serial timing evidence is summarized in
[[ssd1362-datasheet]]. Its 15 ns edge limit sets the complete display-input load acceptance bound
used by the hub's V3 signal-integrity test.
