# SWPA5045S4R7MT data sheet

Sunlord SWPA series data sheet for the [[swpa5045s4r7mt]] buck inductor. The immutable source is
[[../../Datasheets/SWPA5045S4R7MT_C7373218.pdf]].

This source was initially interpreted as binding a 4.7 uH part. Its SWPA5045S electrical table
does not list `SWPA5045S4R7MT`, so the source cannot substantiate the catalog MPN or its claimed
ratings. The contradiction was found before schematic binding. [[nr6045s4r7mt]] replaces it.
