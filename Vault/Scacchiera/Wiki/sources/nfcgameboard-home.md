# Source: NFC Game Board home page

Raw clipping: [Clippings/nfcgameboard.com/home.md](../../Clippings/nfcgameboard.com/home.md). [captured::2026-07-24] [author::[[ben-bulsink]]]

Landing page for [[nfc-game-board-project|NFC Game Board]]. Site tagline "Fast. Simple." States
the project's three headline claims: standard ICode (ISO/IEC 15693) NFC tags so the design isn't
locked to one tag supplier, a reader that "uses standard 15693 functions," and low microcontroller
requirements (8-bit, 20 MHz, 32 KB ROM, 2 KB RAM, 2 KB EEPROM is enough).

Three dated update posts, newest first:

- 2026-06-09: a redesign study is underway to move the reader from
  [[clrc632|CLRC632]] to the NXP PN5180 multi-protocol reader, using community Github libraries,
  matching CLRC632 timing (9 ms Inventory, 12 ms ReadSingleBlock).
- 2026-05-20: partial documentation published, pointing at the software page and the
  [[bitwiseid-method|BitwiseID]] method.
- 2022-10-21: site announcement that the software approach and source code would be published.
