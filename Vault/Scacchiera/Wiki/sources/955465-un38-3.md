# 955465 5,000 mAh UN 38.3 report

Independent transport-safety test report for the pouch cell supplied with [[pisugar3-plus]]. The
immutable source is [[../../Datasheets/955465_PISUGAR5000_UN38.3.pdf]]. Report SA2007199U 01001 was
issued by Dongguan Anci Electronic Technology on 2020-07-20 for cell model 955465.

The tested samples passed UN 38.3 altitude, thermal, vibration, shock, external short circuit,
crush, overcharge, and forced-discharge tests. This establishes transport-test evidence for the
named cell model. It does not certify the completed chessboard, its enclosure, or its charging
thermal environment.
